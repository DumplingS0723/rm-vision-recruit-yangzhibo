- ③ 标定时方格边长输入错误（如实际 25 mm，输入 20 mm）。

数据无变化，同上，此处略

原因：尺度模糊性：单目相机标定无法确定绝对的物理尺度，只能确定相对尺度。世界坐标系的单位缩放（Scale）会被深度信息（Depth/Translation）的反向缩放所抵消。
像素空间优化：标定算法的目标函数是最小化像素平面的重投影误差。无论世界坐标单位如何定义，只要几何结构相似，算法都能收敛到相同的像素级拟合精度，因此重投影误差不受影响。
对测距的影响：虽然标定误差没变，但如果用错误的边长去标定，得到的内参焦距（如果是物理焦距 mm）和外参深度都是错的。在后续使用 solvePnP 测距时，算出来的距离也会是错误的（会偏小 0.8 倍）。这证明了标定板尺寸准确性对于绝对距离测量的重要性。

#### 三、说明

（理论问题回答
内参矩阵含义：
fx，fy：焦距（以像素为单位）。表示图像平面到光心的距离。
cx，cy：主点坐标（光心在图像上的像素位置），通常在图像中心附近。
为何接近：因为像素通常是正方形的，且传感器制造时 X/Y 方向比例一致，所以 fx≈fy

重投影误差：
衡量的是标定精度。
定义：利用计算出的内参和外参，将 3D 世界坐标点重新投影回 2D 图像平面，得到的坐标与实际检测到的角点坐标之间的欧氏距离平均值。
值越小（通常 < 0.5 像素），说明标定越准。
